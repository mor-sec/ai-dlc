# End stage report

**Purpose:** gives the project board a summary of the stage just completed, so it can decide whether to authorise the next stage or close the project.

| | |
|---|---|
| **Created in** | Managing a stage boundary (SB) |
| **Prepared by** | Project manager |
| **Received by** | Project board, in DP (authorise a stage or exception plan) |
| **Derived from** | Current stage plan with actuals, project plan, business case, project log, quality register, next stage plan |

## Composition
1. **PM's summary**
2. **Review of the business case**: is the project still desirable, viable and achievable? Note changes since the last version.
3. **Review of objectives**: stage performance against the seven targets and their tolerances (plan versus actual)
4. **Review of the team's performance**
5. **Review of products**: completed and approved products with quality records, products not completed or carried forward, and off-specifications or concessions
6. **Lessons**: a summary, and whether a lessons report is needed now
7. **Issues and risks**: the current position and the main changes
8. **Forecast for the project and the next stage**: against plan and tolerance
9. **Benefits**: any benefits realised so far

Attach or reference: the next stage plan (or exception plan), the updated project plan, the updated business case, and any revised management approaches.

## Quality criteria
- Products are reported by quality status, with evidence references.
- The business case review reaches an explicit conclusion.
- Forecasts come from the updated plans, not only from this stage's actuals.
- Variances against tolerance are explained.

**Ends with:** decisions required. Approve the end of this stage, authorise the next stage plan, confirm tolerances for the next stage, and approve any updated approaches.

**AI-DLC note:** summarise the AI-DLC records for the stage (units completed, gates passed, audit trail location). Don't attach them raw. Agent learnings that should change agent rules go in the lessons section with a recommendation.
